Function Protocol (FP) Overview

EnduroSat's Function Protocol (FP) is a platform-agnostic C11 service providing session-aware, reliable command/response communication across modular satellite payloads (solar arrays, propulsion units, attitude determination systems, and software radios).

The Vector Assertion Defect in Telemetry Tests

In test.cpp, the unit test suite checked empty response payloads when handling zero-parameter commands. When compiling with standard-library assertions enabled (-D_GLIBCXX_ASSERTIONS): 

// Prior code on empty params:
EXPECT_EQ(params.back(), expected_value); // ABORTS RUN when params.empty()!

Calling params.back() on an empty C++ vector triggered an instant process abort, crashing the test runner before suite completion. We replaced this with bounds-guarded checks.
