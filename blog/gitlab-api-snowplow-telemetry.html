Author: Amir Tahani

Balancing Analytics with Developer Privacy

Developer tools need usage telemetry to prioritize feature development and track agent adoption. However, telemetry must never capture sensitive source code, file paths, repository secrets, or personal identifiable information (PII).

The Snowplow Event Model in GitLab CLI

GitLab CLI instruments command executions via Snowplow structured events:

  • Command Bucketing: Tracks high-level command verbs (e.g. mr create) rather than arguments or flag parameters.
  • Duration Buckets: Quantizes command durations into coarse buckets (e.g. <1s, 1-5s, >10s) to prevent timing-based side-channel analysis.
  • Strict Opt-Out: Respects DO_NOT_TRACK=1 and glab config set no_telemetry true without exceptions.
